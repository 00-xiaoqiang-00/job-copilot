# 🧩 Job Copilot 浏览器一键采集插件安装指南

本插件支持在 **Google Chrome** 或 **Microsoft Edge** 浏览器中一键使用。

---

## 🚀 3 步极速安装：

1. 打开 Chrome 或 Edge 浏览器，在地址栏输入并回车：
   * **Chrome**: `chrome://extensions/`
   * **Edge**: `edge://extensions/`
2. 打开右上角的 **「开发者模式」** 开关 (Developer mode)。
3. 点击左上角的 **【加载已解压的扩展程序】** (Load unpacked)，选择本项目下的 `extension` 文件夹：
   `C:\Users\hxq\.gemini\antigravity\scratch\job-copilot\extension`

---

## 🎯 如何使用：
1. 启动本地 Job Copilot (`http://127.0.0.1:8000`)。
2. 在浏览器中打开任意 **Boss直聘 / 猎聘 / 牛客 / 企业官网** 职位页面。
3. 点击浏览器右上角插件栏的 **【Job Copilot】** 图标，插件将自动抓取岗位、公司、薪资与完整 JD。
4. 点击 **【一键保存到 Job Copilot】**，岗位将秒级录入到你的本地求职看板！
